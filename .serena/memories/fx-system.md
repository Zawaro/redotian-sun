# FX System (FxData + FxSystem)

Change: `openspec/changes/add-fx-system` (issue #455, branch `feat/455-data-driven-fx-system`).

- `scripts/data/FxData.gd` — one `.tres` per one-shot effect. `Kind {SPRITE, PARTICLES}`.
  SPRITE = `AnimatedSprite3D` + `SpriteFrames` (PNG sequence or atlas); PARTICLES = `GPUParticles3D`
  with embedded `ParticleProcessMaterial` + `StandardMaterial3D` draw material. Purely visual — no audio.
- `scripts/core/FxSystem.gd` (autoload, after ShroudSystem/FogRenderer in `project.godot`):
  `play(fx, global_transform, ignore_fog=false, parent=null)`. One-shot lifetime is a per-frame
  accumulator (`_process`), NOT the GPU `finished` signal — deterministic/testable. Layer 1 + nearest filter
  for the low-res pixel-art viewport.
- Fog gating: no spawn when `ShroudSystem.is_cell_visible_to_local(cell)` is false; live effects freeze
  (hidden + `speed_scale = 0`) on `state_changed` and resume on reveal. `ignore_fog=true` for editor previews.
- Assignment: `WeaponData.muzzle_fx` (played in `CombatComponent._fire_weapon` at the world muzzle),
  `WarheadData.impact_fx` (played in `EntityFactory._on_entity_damaged`, the single damage choke point —
  covers hitscan + projectile). Content: `games/ts/fx/*.tres`, textures in `games/ts/assets/fx/`.
- Asset browser has an `FX` category (`MODE_FX`) with a Replay action; it passes `ignore_fog=true` and
  parents under `_object_root`.
- Deferred: projectile flight FX, death FX, fire/burning (#457), pooling (#456), composites.

## Gotcha
Adding a new `class_name` script makes `-s test/run_tests.gd` fail with "Could not find type X" until the
global class cache is refreshed. Run `redot --headless --import` after adding/renaming a `class_name`
script, then run tests. `.uid` files are generated by that import and must be committed.
